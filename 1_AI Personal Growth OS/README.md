# 🚀 AI Personal Growth OS

## 📌 About The Project

AI Personal Growth OS is an AI-powered career and skill analysis platform designed to help students and developers track their learning progress, analyze technical skills, and identify missing areas required for career growth.

The system evaluates user skills based on selected career goals and generates a personalized growth score along with skill recommendations and improvement suggestions.

---

## 🔥 Key Features

- Career Goal Analysis
- Skill Gap Detection
- Growth Score Calculation
- Personalized Recommendations
- Interactive Dashboard
- Database Storage
- Responsive User Interface
